# 🧵 Provador Virtual Zerelle

Aplicativo React de provador virtual 3D para lojas Shopify. O usuário insere suas medidas e recebe uma sugestão de tamanho com base em tabelas específicas para cada produto. Também é possível visualizar a localização das medidas no corpo por meio de um modelo 3D.

## 🚀 Funcionalidades

- Sugestão automática de tamanho com base nas medidas inseridas (busto, cintura e quadril)
- Compatível com múltiplos produtos, com tabelas de medidas customizadas
- Interface moderna e responsiva
- Visualização 3D com `model-viewer`
- Pode ser integrado a páginas e produtos específicos da sua loja Shopify

## 🛠️ Tecnologias

- React
- TailwindCSS
- Framer Motion
- model-viewer
- Shadcn/ui (componentes)
